## AFB I · Eingabe

### 1. Löse die Gleichung nach x auf und gib die Lösungsmenge an.  (Seed 0)

**Aufgabe:** x·(x − 7) = 0

**Lösung:** L = {0; 7}

<details><summary>Hilfen</summary>

1. **Denkanstoß:** Ein Produkt ist genau dann 0, wenn (mindestens) einer der Faktoren 0 ist. Setze jeden Faktor einzeln gleich 0.
2. **Ansatz:** x = 0 oder x − 7 = 0
3. **Lösungsweg:**
   - x·(x − 7) = 0
   - x = 0 oder x − 7 = 0
   - x = 0 oder x = 7
   - L = {0; 7}

</details>
