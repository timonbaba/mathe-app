## AFB III · Eingabe

### 1. Kürze so weit wie möglich.  (Seed 0)

**Aufgabe:** (x² + 16x + 64)/(3x + 24)

**Lösung:** (x + 8)/3

<details><summary>Hilfen</summary>

1. **Denkanstoß:** Zerlege Zähler und Nenner in Faktoren: Im Zähler hilft eine binomische Formel, im Nenner Ausklammern.
2. **Ansatz:** (x² + 16x + 64)/(3x + 24) = ((x + 8)²)/(3·(x + 8))
3. **Lösungsweg:**
   - (x² + 16x + 64)/(3x + 24) = ((x + 8)²)/(3·(x + 8))
   - = (x + 8)/3
   - Hinweis: Das gilt nur für x ≠ −8 – dort wäre der Nenner 0.

</details>

### 2. Kürze so weit wie möglich.  (Seed 1)

**Aufgabe:** (a² − 9)/(a + 3)

**Lösung:** a − 3

<details><summary>Hilfen</summary>

1. **Denkanstoß:** Der Zähler ist eine Differenz zweier Quadrate. Zerlege ihn mit der 3. binomischen Formel – dann kürzt sich ein Faktor.
2. **Ansatz:** (a² − 9)/(a + 3) = ((a + 3)·(a − 3))/(a + 3)
3. **Lösungsweg:**
   - (a² − 9)/(a + 3) = ((a + 3)·(a − 3))/(a + 3)
   - = a − 3
   - Hinweis: Das gilt nur für a ≠ −3 – dort wäre der Nenner 0.

</details>
