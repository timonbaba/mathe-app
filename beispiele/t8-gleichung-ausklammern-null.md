## AFB III · Eingabe

### 1. Löse die Gleichung nach x auf und gib die Lösungsmenge an.  (Seed 0)

**Aufgabe:** x² = 7x

**Lösung:** L = {0; 7}

<details><summary>Hilfen</summary>

1. **Denkanstoß:** Bringe alles auf eine Seite, sodass rechts 0 steht. Klammere dann x aus – und teile nicht durch x, sonst verlierst du eine Lösung.
2. **Ansatz:** x·(x − 7) = 0
3. **Lösungsweg:**
   - x² = 7x   | − 7x
   - x² − 7x = 0
   - x·(x − 7) = 0
   - x = 0 oder x − 7 = 0
   - x = 0 oder x = 7
   - L = {0; 7}

</details>
