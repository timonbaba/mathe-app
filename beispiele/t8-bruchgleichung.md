### 1. Gib an, welche Zahlen für x ausgeschlossen sind, und löse die Gleichung (Variable x). Beispiel: „x ≠ 0; L = {2}“.  (Seed 0)

**Aufgabe:** 3/x − 3 = −6

**Lösung:** x ≠ 0; L = {−1}

<details><summary>Hilfen</summary>

1. **Denkanstoß:** Überlege zuerst, für welche Zahlen ein Nenner 0 wird – die sind ausgeschlossen. Multipliziere dann beide Seiten mit allen Nennern. Prüfe am Ende, ob deine Lösung erlaubt ist.
2. **Ansatz:** Ausgeschlossen: x ≠ 0 (dort wäre ein Nenner 0)
3. **Lösungsweg:**
   - Ausgeschlossen: x ≠ 0 (dort wäre ein Nenner 0)
   - 3/x − 3 = −6   | · x

   - x = −1
   - Probe: x = −1 ist nicht ausgeschlossen.
   - x ≠ 0; L = {−1}

</details>
